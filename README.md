A lightweight executable that modifies the hardcoded memory allocation in Empire: Total War, bypassing the original 32,768 entity limit to allow for massive, stable battles with over 51,000 troops.

Features
Automated Patching: Safely injects the 4 necessary hex modifications directly into Empire.exe.

Automatic Backups: Creates an Empire.exe.bak backup file before making any changes.

Safety Checks: Verifies existing bytes to prevent double-patching or corrupting incompatible game versions.

Installation & Usage
Download empire_patcher.exe from the Releases tab.

Place the executable directly into your Empire: Total War root directory (the same folder that contains Empire.exe).

Double-click empire_patcher.exe.

The command prompt will open, create a backup, apply the patches, and display a success message.

Launch the game.

To uninstall, delete the patched Empire.exe and rename Empire.exe.bak back to Empire.exe.
